# Analyst Trend Workflow

## Review Flow

1. Open the Fraud Monitor dashboard.
2. Check provider readiness and health.
3. Run the standard `fraud` scan or enable the local scheduler.
4. Review the Trends section before working the queue.
5. Use official-source alerts to prioritize high-confidence public records.
6. Review stored results and mark them pending, relevant, or not relevant.
7. Save useful source links as evidence with analyst notes.
8. Write findings only after reviewing source context.
9. Export Markdown or JSON when the reviewed evidence is ready.

## Trend Panels

The Trends section shows:

- Top fraud categories this week.
- High-confidence official-source alerts.
- State activity.
- Payment rail mentions.
- Emerging keywords.
- Provider health.

Trend summaries are based on stored local results. They are triage signals, not automated allegations.

## Responsible Use

Keep review language cautious and source-attributed. Do not target private individuals, scrape login-gated sources, or store full copyrighted article bodies. Redact sensitive details before sharing exports outside the local review context.
